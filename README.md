# Явка — учёт посещаемости учебной группы

«Явка» — приложение для ведения журнала посещаемости учебной группы. Оно объединяет список студентов, расписание занятий и отметки за проведённые пары. Ответственный выбирает дату и занятие, отмечает присутствие или отсутствие с указанием причины, а приложение подсчитывает пропущенные академические часы.

Расписание построено на чередовании двух учебных недель и может редактироваться под группу. Сохранённые отметки дают сводные сведения по студентам и по группе за выбранный месяц или весь период. Для обмена результатами предусмотрен экспорт в XLSX: ведомость показывает пропуски по датам и причинам. Она не содержит отметок о присутствии и поэтому не заменяет полную резервную копию журнала.

Веб-интерфейс написан на HTML, CSS и JavaScript. Основной журнал сохраняется в локальном хранилище браузера, на устройстве, где ведётся учёт; автоматической синхронизации между устройствами нет. Для формирования таблиц используется ExcelJS. В репозитории также есть оболочки приложения для настольной версии на Electron и мобильной версии на Capacitor.

В исходном коде сохранён дополнительный сценарий сбора ответов студентов по ссылке через Firebase и Firestore. Его настройка и работа зависят от конфигурации облачного проекта и правил доступа. До использования реальных данных студентов этот режим требует отдельной проверки, поэтому его следует рассматривать как экспериментальную возможность проекта.

«Явка» задумана как практичный инструмент для повседневного учёта в одной учебной группе. Текущая версия автоматизирует повторяющиеся расчёты и подготовку ведомости, сохраняя за ответственным решение о том, какие отметки вносить и как трактовать причину отсутствия.
